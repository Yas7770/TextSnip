TEXTSNIP 2.4.0

INSTALL
Run TextSnip-Setup.exe. Exit any running copy from its tray menu first.
Installs for your account with optional desktop shortcut and start-at-sign-in.
No administrator access is needed. The app is unsigned.

TRAY STARTUP
TextSnip starts quietly in the system tray without opening a window or adding
an active taskbar button. Right-click its tray icon > Open to view the app.
An opened preview window appears on the taskbar while you use it.
Closing it returns the app to the tray. Choose Exit in the tray menu to quit.
The close reminder has a Don't show this again checkbox, saved across restarts.

CAPTURE TEXT
Ctrl + Shift + 2, or tray menu > Capture text.
Select the Text tab for New capture, or use the text shortcut/tray action.
Drag around visible text. Esc cancels. Review/edit the result in the Text tab.
Highlight a portion and click Copy selection, or use Copy all.
Capture does not change your clipboard automatically.

TAKE A SCREENSHOT
Ctrl + Shift + 3, or tray menu > Take screenshot.
You can also select the Screenshot tab, then click New capture.
Drag an area to capture it. The Screenshot tab previews the original pixels.
Save PNG chooses a file location; Copy image explicitly copies the image.
The previous screenshot stays in memory until replaced or the app exits.
Unsaved screenshots are not kept after exiting.
